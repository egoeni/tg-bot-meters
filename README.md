# Telegram-бот учёта показаний счётчиков

Личный бот для семьи: принимает фото счётчиков, распознаёт показания через GigaChat Vision, ведёт историю, считает расход и стоимость коммунальных услуг, напоминает о сдаче данных.

## Возможности

- 📸 **Распознавание показаний с фото** через GigaChat Vision (с предобработкой изображения)
- 🔢 **Автоопределение счётчика** по заводскому номеру и особенностям
- ✍️ **Ручной ввод** (`/add`) — если фото сделать невозможно
- 📊 **Отчёты** (`/report`) — расход и стоимость за месяц с учётом истории тарифов
- 🔔 **Умные напоминания** — с 25-го числа, только по несданным счётчикам
- 💾 **Локальное хранение** — SQLite + JSON

## Архитектура

- **aiogram 3** — Telegram-бот
- **GigaChat SDK** — распознавание показаний и номеров через Vision
- **APScheduler** — планировщик напоминаний и очистки
- **SQLite** — история показаний, счётчики, тарифы
- **Pillow** — предобработка фото (уменьшение, ч/б, контраст)

## Установка

### 1. Создать виртуальное окружение

```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Linux/macOS:
source venv/bin/activate
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Настроить переменные окружения

Скопируйте `.env.example` в `.env` и заполните:

```dotenv
BOT_TOKEN=ваш_токен_от_BotFather
GIGACHAT_CREDENTIALS=ваш_ключ_из_Sber_Developer_Studio
```

### 4. Запустить

```bash
python my_ar_bot.py
```

## Команды бота

| Команда | Действие |
| :--- | :--- |
| `/start` | Справка по командам |
| `/set` | Активировать бота в этом чате, создать счётчики |
| `/stop` | Деактивировать бота в чате |
| `/meters` | Список счётчиков с серийными номерами |
| `/add` | Ручной ввод показаний (без фото) |
| `/last` | Последние показания по всем счётчикам |
| `/report [YYYY-MM]` | Отчёт за месяц: расход и стоимость |
| `/mute` | Приостановить напоминания |
| `/unmute` | Возобновить напоминания |
| Фото | Распознать показания через GigaChat |

## Настройка счётчиков

После `/set` создаются 5 счётчиков по умолчанию:

| Код | Название | Единица |
| :--- | :--- | :--- |
| `hvs` | ХВС | м³ |
| `gvs` | ГВС | м³ |
| `el_day` | Электро день | кВт·ч |
| `el_night` | Электро ночь | кВт·ч |
| `heat` | Тепло | Гкал |
| `gaz` | Газ | м³ |

**Серийные номера** задаются вручную в таблице `meters` (поле `serial`). По ним работает автоопределение.

**Особенности счетчика** задаются вручную в таблице `meters` (поле `features`). Дополнительные особенности, позволяющие распознать счетчик

**Активность счётчика** — поле `active` (`1` — учитывается, `0` — скрыт).

**Тарифы** задаются в таблице `tariffs` (поле `rate`), поддерживают историю через `valid_from`.


## Структура проекта

```
.
├── my_ar_bot.py         # основной код бота
├── requirements.txt     # зависимости
├── .env.example         # шаблон переменных окружения
├── .gitignore
└── README.md
```

Файлы, создающиеся при первом запуске:

- `bot.db` — SQLite с историей показаний, счётчиками и тарифами
- `targets.json` — список чатов для напоминаний
- `muted.json` — чаты с приостановленными напоминаниями
- `chats.json` - список чатов в которых добавили/удалили бота


## Известные ограничения

- Точность распознавания зависит от качества фото. GigaChat Vision может ошибаться на размытых, тёмных или снятых под углом снимках.
